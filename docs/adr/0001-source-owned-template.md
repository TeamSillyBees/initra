# 将 initra 改为源码内置的服务模板

initra 改为完整服务模板，自身提供的基础能力随项目源码交付，不再要求业务项目安装 initra CLI 或通过外部 initra 模块获取这些能力。这让开发者和编程 Agent 能在当前项目直接查看、修改相关实现，代价是派生项目需要自行维护这些能力的后续变化。

根目录提供完整服务，统一为单一 Go module，基础能力位于 internal/platform，保留当前技术栈、业务模块和测试；移除 CLI 分发、模板镜像、同步工具及多模块结构。允许随仓库提供轻量 Go 源码工具，承担项目改名、密钥与管理员初始化。

Ent 生成代码随仓库提交，CI 检查可重生成性；初始化只修改本地文件，迁移和种子写入显式执行，重复初始化保留凭据。旧框架 skill、模块能力说明和安装流程全部移除，只保留精简的项目开发约定。
